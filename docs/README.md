# BlueMolecule documentation

> **BlueMolecule is a vibe-coded project.** An AI assistant (Claude, by Anthropic) wrote it from its author's
> instructions, and it was tested mostly on synthetic files. Check numbers that matter against your original output
> files. [Read more](vibe-coding.md).

**Using BlueMolecule**

1. [Installation](installation.md): Linux, Windows, macOS and the single HTML file; window types; Open Babel.
2. [User guide](user-guide.md): the window, mouse and keyboard, toolbar, tabs, plots, saving and exporting.
3. [Analysing outputs](analysing-outputs.md): contents overview, optimisations and convergence, scans and IRC,
   vibrations, IR, Raman, UV-Vis, ECD and NMR spectra, excited states, orbitals and volumes, charges.
4. [QM/MM and ONIOM](qmmm-oniom.md): what is read from each program, energies, layer views.
5. [Representations](representations.md): display rows, styles, colour schemes, presets, proteins, nucleic acids,
   lipids, glycans (SNFG).
6. [Selection language](selection-language.md): the complete reference.
7. [Building and editing](building-and-editing.md): build tools, library, hydrogens, clean-up, symmetry,
   coordinates, calculation inputs.
8. [File formats](file-formats.md): everything that can be opened and saved.
9. [Large files and trajectories](large-files-and-trajectories.md): big outputs, MD topologies and trajectories,
   memory.
10. [Troubleshooting](troubleshooting.md).
